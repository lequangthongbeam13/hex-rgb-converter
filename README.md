# Hex RGB Converter

A small web page that converts colors in both directions:

- **Hex to RGB**: type a hex code like `#ff8800` or `f80` and get `255, 136, 0`.
- **RGB to Hex**: type three numbers like `154, 28, 212` and get `#9a1cd4`.

Each result shows a small color preview. Wrong input gets a clear error message.

## How to run

No install needed. Open `index.html` in any browser (Chrome, Safari, Firefox, Edge).
